# MangoWM

[MangoWM](https://github.com/mangowm/mango) Wayland compositor config, with
[Noctalia](https://noctalia.dev) as bar, launcher and notifications.

| File | What |
|---|---|
| `config.conf` | Environment, autostart, monitor layout; pulls in `conf.d/` |
| `conf.d/appearance.conf` | Cursor, borders, gaps, blur |
| `conf.d/bind.conf` | Key and mouse bindings |
| `conf.d/rules.conf` | Window rules (`rules-example.conf` has more examples) |
| `scripts/autostart.sh` | Starts Noctalia |
| `wall/` | Wallpapers |

`noctalia.conf` is generated by Noctalia and not tracked.

## Keys

| Keys | Action |
|---|---|
| `Alt+Return` | Terminal (Kitty) |
| `Alt+D` | Launcher (Noctalia) |
| `Alt+E` | File manager (Yazi in Kitty) |
| `Alt+1..9` / `Alt+Shift+1..9` | Go to / move window to workspace |
| `Alt+arrows` | Focus window in that direction |
| `Alt+Space` | Play/pause media |
| `Alt+Q` | Close window |
| `Super+F` | Fullscreen |
| `Super+1/2/3` | Layout: scroller / fair / vertical scroller |
| `Super+Shift+S` | Screenshot a region (Noctalia) |
| `Super+R` | Reload config |
| `Super+Shift+Q` | Quit MangoWM |

## Displays

| Monitor | Mode | Position |
|---|---|---|
| AOC 2590G4 | 1920x1080 @ 144Hz | left, x:0 (XWayland breaks with negative x) |
| AOC C27G4ZXU | 1920x1080 @ 280Hz | right, x:1920, primary |
| eDP-1 (laptop) | 2880x1800 @ 120Hz, scale 1.5 | below, y:1080 |

## Look

Bibata Modern Classic cursor (24px), 2px borders with 4px radius, no inner
gaps and 2px outer, blur on windows and layers.

## Install

```bash
sudo pacman -S kitty fish
paru -S noctalia
cp -r mango ~/.config/   # NixOS deploys it for you, see ../nix
```

Then pick MangoWM at the login screen, or run `mango`.
