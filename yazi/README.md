# Yazi

[Yazi](https://yazi-rs.github.io/) terminal file manager config (`yazi.toml`):

- Column ratio 1:4:3, sorted by last modified with directories first
- Hidden files and symlink targets shown, size and date per line
- Previews wrap, capped at 1000x800 with 80% image quality

Open it with `Alt+E` in MangoWM, or `y` in fish, which also `cd`s to where
you quit (see [`../fish`](../fish/README.md)).
