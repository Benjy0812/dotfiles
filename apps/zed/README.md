# Zed

[Zed](https://zed.dev) editor config.

| File | Lives at | What |
|---|---|---|
| `settings.json` | `~/.config/zed/` | Editor settings; dark mode with the Glass theme |
| `themes/Glass.json` | `~/.config/zed/themes/` | The custom translucent Glass theme |
| `../.zed/settings.json` | `~/.config/.zed/` | Per-language settings (e.g. 2-space CSS) for this folder |
