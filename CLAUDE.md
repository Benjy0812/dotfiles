# Dotfiles repo: notes for agents

- **Layout:** `common/` is linked on every profile; `profiles/<os>/` adds or
  overrides files (same path = the profile wins). `dotfiles.bash link` runs stow
  on both. NixOS deploys through home-manager (`profiles/nixos/nix/`), not stow.
- **The live config is the repo.** Files in `~/.config` are links into here, so
  editing either edits both. After moving or deleting repo files, run
  `./dotfiles.bash link` and `./dotfiles.bash doctor`, or live links dangle.
- **Test before committing:** `./tests.bash` (also runs the plugin tests) and
  `shellcheck -S warning dotfiles.bash tests.bash`. New `dotfiles.bash`
  behaviour gets a check in `tests.bash` first.
- **Version control:** GitButler (`but status`, `but diff`, `but commit -b <branch> <ids>`).
  Other agents may share the workspace: commit only your own IDs.
- **`.gitignore` is a whitelist** (`/*` plus `!` entries). A new top-level file
  or folder stays untracked until it is listed.
- **Never commit** `~/.config/omarchy/shell.json` into a profile: it is per
  machine and only goes to `machines/<host>/` via `./dotfiles.bash snapshot`.
  Same for `fish_variables` and `profiles/omarchy/fish/config.fish` (ignored).
- **Omarchy plugins** (`profiles/omarchy/omarchy/plugins/<id>/`): `manifest.json`,
  a README, a `test_*.lua` or `test_*.js` if there is logic, and Hyprland-side
  Lua loaded by one `dofile` line at the end of `hypr/custom.lua`.
- **benjy.bar** keeps only its own files and `bar.patch`; the stock bar files in
  `~/.config/omarchy/plugins/benjy.bar/` are generated by `./dotfiles.bash
bar-update`. Edit the live `Bar.qml`, then `bar-save`.
- **Per-host Hyprland:** monitors and HDR go in `profiles/omarchy/hypr/hosts/<hostname>.lua`.
- After shell (Quickshell) service changes: `omarchy restart shell`. After
  Hyprland changes: `hyprctl reload && hyprctl configerrors`.
