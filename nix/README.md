# Nix

The flake (`../flake.nix`) has two outputs:

- **`nixosConfigurations.benjy`** - full NixOS system. Installs MangoWM, makes
  it the default SDDM session, and deploys the dotfiles through home-manager.
- **`homeConfigurations.benjy`** - standalone home-manager profile for
  non-NixOS machines (e.g. CachyOS). Installs packages only and never touches
  `~/.config`.

| Path | What |
|---|---|
| `nixos/configuration.nix` | System: boot, SDDM + MangoWM, fish, packages |
| `nixos/hardware-configuration.nix` | Generated by `nixos-generate-config` |
| `nixos/home.nix` | home-manager packages, shared by both outputs |
| `nixos/dotfiles.nix` | Which repo configs get deployed into `~/.config` (NixOS only) |
| `nixos/standalone.nix` | Extra settings for the standalone profile |
| `nixos-wsl/` | Separate WSL config, not part of the flake; `copy-nix.sh` copies it to `/etc/nixos` |

## Use

```bash
# Rebuild from the checked-out repo
sudo nixos-rebuild switch --flake ~/Projects/dotfiles#benjy

# Fresh install, repo not cloned yet
sudo nixos-rebuild switch --flake github:Benjy0812/dotfiles#benjy

# Standalone profile on another distro (Nix must be installed)
nix run github:nix-community/home-manager -- switch --flake ~/Projects/dotfiles#benjy
```

A flake only sees files committed to git, so commit new configs before
rebuilding. Removing a config means removing it from `nixos/dotfiles.nix`
too, or the rebuild fails on the missing file.
