# Kitty

[Kitty](https://sw.kovidgoyal.net/kitty/) terminal config (`kitty.conf`):

- JetBrains Mono 12pt, fish as the shell
- 50% background opacity, 10px padding
- 10,000 lines of scrollback
- Low input and repaint delay, synced to the monitor

Install JetBrains Mono first (`sudo pacman -S ttf-jetbrains-mono`), or Kitty
falls back to another font.
